# Wide Docks v1.0.0

Initial production release of Wide Docks.

Wide Docks lets Godot's Scene, Inspector, FileSystem, and other side docks
expand farther on narrow/mobile displays while preserving Godot's native
divider interaction.

## Highlights

- Production baseline: Godot 4.7.2 stable.
- Designed and manually validated on the Android editor.
- Independent left/right center boundaries.
- Smooth visual latching throughout the drag.
- No editor-control reparenting.
- No global input interception.
- No per-frame splitter correction.
- No `split_offsets` forcing.
- Free to use under the FDOF Tooling Attribution License 1.0.
- No visible credit required in games/projects made with the plugin.
- Visible FDOF credit required only for redistributed or derivative tooling.

## Install

Copy `addons/wide_docks/` into a Godot project and enable **Wide Docks** under
**Project Settings → Plugins**.
