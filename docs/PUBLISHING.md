Create a tag:

```text

```

Use `RELEASE_NOTES_v1.0.0.md` as the initial release body.

Attach the plugin-only ZIP generated by:

```bash
python scripts/check_release.py --package
```

## Godot Asset Library / Asset Store preparation

Current Godot publishing guidance requires or recommends:

- a working asset for the declared Godot version;
- a proper `.gitignore`;
- a repository a repository license whose license choice matches the store listing;
- installable addon files under `addons/<asset_name>/`;
- a README and license copy inside the plugin folder;
- a direct-link square icon;
- correct English name/description;
- explicit version compatibility;
- current Asset Store AI-usage disclosure where applicable.

This repository is structured for those requirements.

Suggested listing metadata:

**Name:** Wide Docks

**Type:** Addon / Editor plugin

**Version:** 1.0.0

**Minimum verified Godot version:** 4.7.2

**License:** FDOF Tooling Attribution License 1.0

**Short description:**

> Expand Godot's side editor docks farther on narrow and mobile displays
> while keeping the native divider interaction.

**Tags:** editor, mobile, Android, accessibility, workflow, productivity

Before submission, replace `FullDeckOfFools` placeholders in the addon README and
release metadata with the actual GitHub owner/organization.
